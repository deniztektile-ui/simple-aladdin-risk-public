# Simple Aladdin Risk (Public)

Упрощённый учебный прототип системы управления рисками портфеля (вдохновлённый BlackRock Aladdin).

⚠️ **Важно**: Это учебный и сильно упрощённый прототип. Не для реальной торговли.

## Быстрый старт

```bash
git clone https://github.com/deniztektile-ui/simple-aladdin-risk-public.git
cd simple-aladdin-risk-public
pip3 install -r requirements.txt
streamlit run app.py
```

## Что умеет

- Анализ риска портфеля (VaR, CVaR, Max Drawdown, Sharpe)
- Интерактивный дашборд на Streamlit
- Корреляции, графики доходности и просадок
